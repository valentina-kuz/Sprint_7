Яндекс.Самокат API - Автотесты

Автоматизированные тесты для API учебного сервиса Яндекс.Самокат (https://qa-scooter.praktikum-services.ru/)

## Описание проекта

Проект содержит автоматизированные тесты для проверки функциональности API сервиса Яндекс.Самокат:
- **Тесты курьеров** - создание, авторизация и удаление курьеров
- **Тесты заказов** - создание заказов с разными параметрами, получение списка и управление заказами
- **Дополнительные тесты** - принятие заказов курьерами, получение заказа по номеру

## Технологии

- **Python** - язык программирования
- **pytest** - фреймворк для тестирования
- **requests** - HTTP клиент для API запросов
- **Allure** - генерация отчетов
- **Faker** - генерация тестовых данных

## Установка и запуск

### Предварительные требования

1. Установите Python 3.8+
2. Установите pip (менеджер пакетов Python)
3. Установите Allure для генерации отчетов (опционально)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск тестов

#### Запуск всех тестов
```bash
pytest tests/ -v --alluredir=allure-results
```

#### Запуск тестов курьеров
```bash
pytest tests/test_courier_create.py tests/test_courier_login.py tests/test_courier_delete.py -v --alluredir=allure-results
```

#### Запуск тестов заказов
```bash
pytest tests/test_order_create.py tests/test_orders_list.py tests/test_order_accept.py tests/test_order_get_by_track.py -v --alluredir=allure-results
```

#### Запуск определенного файла тестов
```bash
pytest tests/test_courier_create.py -v --alluredir=allure-results
```

### Генерация отчета Allure

```bash
allure serve allure-results
```

## Описание тестов

### Тесты курьеров (9 базовых тестов)
- **test_courier_create.py** - создание курьеров (3 теста)
  - Успешное создание курьера
  - Проверка невозможности создания дублей
  - Параметризованная проверка валидации обязательных полей (4 варианта)
- **test_courier_login.py** - авторизация курьеров (3 теста)
  - Успешная авторизация с возвратом ID
  - Проверка ошибок при пустых полях (логин и пароль)
  - Ошибка при авторизации несуществующего пользователя
- **test_courier_delete.py** - удаление курьеров (3 теста)
  - Успешное удаление курьера
  - Ошибка при удалении без ID
  - Ошибка при несуществующем ID

### Тесты заказов (12 базовых тестов)
- **test_order_create.py** - создание заказов (3 теста)
  - Параметризованное создание с разными цветами (4 варианта)
  - Проверка наличия track в ответе
  - Создание с комбинацией цветов BLACK и GREY
- **test_orders_list.py** - получение списка заказов (3 теста)
  - Получение списка заказов с проверкой структуры
  - Проверка структуры данных в заказах
  - Доступность без авторизации
- **test_order_accept.py** - принятие заказов (3 теста)
  - Успешное принятие заказа курьером
  - Ошибка при отсутствии ID курьера
  - Ошибка при несуществующем заказе
- **test_order_get_by_track.py** - получение по номеру (3 теста)
  - Успешное получение заказа по track номеру
  - Ошибка при запросе без номера заказа
  - Ошибка при несуществующем номере заказа

**Всего: 21 базовый тест (27 выполнений с учетом параметризации)**

## Особенности реализации

### Архитектура
- **Модульная архитектура** - разделение на config, helpers, data, tests
- **APIClient** - базовый класс для HTTP запросов с единой обработкой
- **CourierAPI/OrderAPI** - специфичные API классы для курьеров и заказов
- **DataGenerator** - генератор тестовых данных с fallback логикой

### Технические решения
- **Фикстуры pytest** для автоматического создания и очистки тестовых данных
- **Параметризация тестов** для покрытия разных сценариев одним тестом
- **Allure отчеты** с подробной документацией каждого шага
- **Независимость тестов** - каждый тест создает и удаляет свои данные
- **Обработка ошибок** - graceful fallback при недоступности Faker
- **Типизация** - использование type hints для лучшей читаемости кода
- **Централизованная конфигурация** - все настройки в config/settings.py
